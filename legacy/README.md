# Prototipo anterior

Esta carpeta conserva la version Tkinter/TCP desarrollada para el curso de
Criptografia. No forma parte de la aplicacion web final y no debe desplegarse:
carece de TLS, autenticacion de cuentas, persistencia asincrona y varios
controles operativos incorporados en la version actual.

Se mantiene unicamente como evidencia de la evolucion del proyecto.
